# СТАНОК — личный тренер

Одностраничное приложение для собственных тренировок и питания: журнал тренировок
с прогрессиями, дневник КБЖУ, лог веса с графиком, напоминания.

Открыть: **https://a1exandrs1m.github.io/stanok/**

## Что это технически

Один самодостаточный файл `index.html`. Весь CSS и JS внутри, без сборщиков,
без npm, без бэкенда. Внешние зависимости — только шрифты Google Fonts
(с фолбэк-стеками, offline приложение работает целиком). Графики нарисованы
на `<canvas>` и инлайновым SVG.

## Где лежат данные

Всё состояние — в `localStorage` браузера, ключ `trainer_v1`. Никуда не
отправляется: у приложения нет ни сервера, ни аналитики, ни единого сетевого
запроса, кроме подгрузки шрифтов.

Отсюда два следствия:

- **Хранилище привязано к адресу и к устройству.** Телефон и ПК — две
  независимые копии.
- **Перенос — только вручную**, через Настройки → «Скачать бэкап» и
  «Загрузить бэкап». Импорт сливает записи по времени изменения, а не
  перезаписывает вслепую.

Файлы бэкапов (`trainer-backup-*.json`) содержат личные данные и занесены
в `.gitignore` — коммитить их нельзя.

## Как поставить на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome → меню → «Добавить на главный экран».

Приложение запустится в полный экран, без адресной строки.

## Ограничение напоминаний

Напоминания работают через `Notification API` и живут, только пока приложение
открыто в браузере. Фоновые уведомления требуют service worker и настоящего
сервера — этого здесь намеренно нет. Если разрешение на уведомления не выдано,
напоминание появляется баннером на экране «Сегодня».

## Обновление

Правим `index.html`, коммитим, пушим в `main` — GitHub Pages раздаёт новую
версию по тому же адресу, накопленные данные при этом остаются на месте.
